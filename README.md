# Good-Send Courier Services Website

## Project Overview

Good-Send is a courier services website designed to provide customers with clear and accessible information about delivery and logistics services.

The website provides information about Good-Send, its available services, contact details and frequently asked questions. The website is designed to be simple, professional and easy to navigate on different screen sizes.

## Project Purpose

The purpose of the Good-Send website is to create a user-friendly online platform where customers can:

- Learn about Good-Send and its services.
- View different delivery and logistics services.
- Find contact information.
- Read answers to frequently asked questions.
- Navigate easily between the different pages.
- Access the website on desktop, tablet and mobile devices.

## Target Users

The website is designed for:

- Individuals who need courier and delivery services.
- Small and medium-sized businesses.
- Online sellers and e-commerce businesses.
- Larger businesses that require delivery and logistics services.

## Website Pages

The website contains the following pages:

- **Home** – Introduces Good-Send and its delivery options.
- **About Us** – Provides information about Good-Send and its mission.
- **Services** – Describes the different delivery and logistics services offered.
- **Contact** – Provides telephone and email contact information.
- **FAQ** – Provides answers to common questions about Good-Send services.

## Website Features

The website includes:

- Navigation menu linking all main pages.
- Responsive page layouts.
- Structured headings and sections.
- Delivery and service information.
- Contact information with clickable telephone and email links.
- Frequently Asked Questions section.
- Interactive FAQ buttons using JavaScript.
- Courier-related imagery.
- Hover effects for navigation and service elements.
- Mobile-friendly layouts.
- Semantic HTML structure.
- Responsive service cards.

## Part 2 Development

Part 2 focused on improving the website's CSS styling, layout, responsiveness, readability and user experience.

### Layout Improvements

The website layout was improved by:

- Creating structured page sections using HTML5 semantic elements.
- Improving spacing and alignment between website elements.
- Creating a responsive grid layout for the Services page.
- Improving the presentation of delivery options on the Home page.
- Creating individual service cards.
- Creating separate content sections for the About Us, Contact and FAQ pages.

### Typography

Typography was improved to create a clearer visual hierarchy.

The website uses:

- Large headings for page titles.
- Subheadings for individual sections.
- Readable paragraph sizes.
- Improved line spacing.
- Consistent text formatting across pages.

### Navigation

The navigation system was improved across all website pages.

The navigation includes:

- Home
- About Us
- Services
- Contact
- FAQ

The current page is highlighted using an active navigation style.

Hover effects were also added to make navigation links more interactive.

### Responsive Design

Responsive CSS was added using media queries.

The website was designed to adapt to:

- Desktop computers.
- Tablets.
- Mobile phones.

On smaller screens:

- Navigation links are displayed vertically.
- Service cards change from two columns to one column.
- Images automatically resize.
- Text sizes are adjusted.
- Content spacing is reduced where necessary.

## Accessibility

Several accessibility improvements were made to the website.

These include:

- Adding alternative text to images.
- Using semantic HTML elements.
- Maintaining a logical heading structure.
- Using readable font sizes.
- Improving spacing between sections.
- Providing clickable telephone and email links.
- Making buttons and navigation elements easier to identify.

## Semantic HTML

Semantic HTML elements were introduced to improve the structure of the website.

Examples include:

- `<nav>` for the main navigation.
- `<main>` for the primary page content.
- `<section>` for major content sections.
- `<article>` for individual service and FAQ items.
- `<h1>`, `<h2>` and `<h3>` for headings.
